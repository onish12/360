PHASER360 H15I — ISOLATED HDA CRST GATE

H15I temporarily replaces IntcAudioBus as function driver.

It requires the exact H15H baseline and then performs only:
  HDA GCTL.CRST: 0 -> 1 -> 0

HDA BAR is mapped PAGE_READWRITE because GCTL must be written.
DSP BAR is mapped PAGE_READONLY and is never written.

No PCI config write, ADSPCS write, DMA, interrupt ownership, firmware load,
DSP boot or playback is permitted.

Run only RUN_H15I_TRANSACTION.cmd as Administrator.

Expected success:
  STATUS=H15I_HDA_CRST_AND_ROLLBACK_COMPLETE
  HANDOFF_COMPLETED=TRUE
  WRITE_RESTORE_COMPLETED=TRUE
  SNAPSHOT_COMPLETED=TRUE
  BASELINE_RESTORED=TRUE
  TRUST_RESTORED=TRUE

Then send RESULT_H15I_TRANSACTION_*.zip.
