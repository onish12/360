PHASER360 H15H OFFLINE ROLLBACK

Use only if Windows cannot boot after the H15H function-driver transaction.

1. Enter Windows Recovery Environment -> Command Prompt.
2. Identify the offline Windows volume. Do NOT assume C:.
3. Read H15hPublishedInf.txt and note the PHASER360 oemNN.inf.
4. Confirm it:
   dism /Image:<WINDOWS_VOLUME>:\ /Get-Drivers /Format:Table
5. Remove ONLY that H15H package:
   dism /Image:<WINDOWS_VOLUME>:\ /Remove-Driver /Driver:oemNN.inf
6. Reboot.

Do NOT remove oem14.inf.

Verified Intel baseline:
  Service=IntcAudioBus
  INF=oem14.inf
  Version=9.22.0.4832
  Provider=Intel(R) Corporation

H15H owns only PCI config 0x44 bit2 and 0x48 bit1 during the synchronous
transaction. It performs no MMIO write, DMA, IRQ ownership or firmware boot.
